# Phase 1 plan: voice round-trip (no connectors)

Restated from docs/design/SPEC.md §14.1 before writing code.

1. **Scaffold first.** Flat `spark/` package managed by uv (Python 3.11). All components are ABCs in `spark/interfaces.py` (`WakeWordDetector`, `VAD`, `STT`, `TTS`, `Brain`, plus mic and player). Backends are chosen only through `config.yaml` via string-path entries in `spark/registry.py`, and heavy libraries are imported lazily inside backend constructors.
2. **Config.** `spark/config.py` uses pydantic-settings, layering `config.yaml`, then `.env`, then environment variables (`SPARK_` prefix, `__` nesting). Every backend, threshold, and model name gets a commented default in `config.yaml`.
3. **Audio path.** A 16 kHz mono int16 mic stream (sounddevice/WASAPI) feeds a ring buffer that is re-chunked per consumer (Porcupine 512, openWakeWord 1280, Silero 512). The player is interruptible, with generated earcons (wake chime, thinking tick, error tone). A Recorder handles pre-roll, ~700 ms silence endpointing, a max length, and a no-speech timeout.
4. **Default backends.** Porcupine for the wake word (custom "Hey Spark" `.ppn`; openWakeWord is optional), Silero VAD via the ONNX model bundled with faster-whisper (no torch), faster-whisper `base.en` int8 on CPU, and Piper TTS streamed sentence by sentence. Deepgram, Kokoro, and ElevenLabs are real but optional extras.
5. **Brain v1.** A long-lived `ClaudeSDKClient` with partial-message streaming and no tools, a voice system prompt, `sanitize_for_speech` on every sentence, a reset after 10 min idle or on "new topic", and `MockBrain` for tests and offline use. SDK APIs are verified against the installed package first (`docs/sdk_notes.md`).
6. **App loop.** An asyncio state machine IDLE → LISTENING → THINKING → SPEAKING → FOLLOW_UP (8 s window), with an injectable clock. Blocking CPU work runs in `asyncio.to_thread`. Errors play the error earcon and return to IDLE. The barge-in hook exists but is off until Phase 3.
7. **Latency.** `TurnTimer` marks wake, end of speech, STT done, brain first token, first sentence, and first audio, and writes a per-turn breakdown to jsonl. Models preload at startup and the brain client is warmed.
8. **CLI and doctor.** `python -m spark` supports `run`, `--text`, `--no-tts`, `--debug-audio`, and backend overrides, plus `doctor`, `models download`, `bench stt|tts|brain|latency|false-wake`, and `record-fixture`. The doctor reports ✔/✖ with a fix for each check and exits non-zero on a required failure.
9. **Tests.** Everything is tested with fakes (FakeMic, FakeWakeWord, FakeVAD, FakeSTT, FakeTTS, MockBrain) plus synthesized wav fixtures (Piper plus noise) for STT accuracy and VAD endpointing. Model-dependent tests skip cleanly and live tests are `-m live`. A swap test proves STT and TTS change via config alone.
10. **Acceptance.** Items that need the laptop's mic, speaker, or credentials (the spoken answer, median latency < 2 s over 10 trials, doctor passing, < 1 false wake in 30 min) go to `docs/HUMAN_CHECKLIST.md` with the exact command. They are never self-certified.
